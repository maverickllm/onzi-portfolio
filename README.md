# Onzi Portfolio

Portfolio personal de Esteban Herrero — Product Designer & Full Stack Developer.

## 🛠️ Stack
- **Next.js 15** (App Router) + **TypeScript**
- **Tailwind CSS v4** (configuración con `@theme`)
- **Framer Motion** (animaciones de entrada y texto rotante)
- **GSAP + Lenis** (scroll suave)
- **Lucide React** (iconografía)

## 🎨 Decisiones técnicas
- Animación de texto con `AnimatePresence` y curva de easing expo-out
- Colores de marca centralizados en Tailwind (`onzi-orange`, `onzi-dark`)
- Montserrat optimizada con `next/font` (display swap, subsets latin)
- Navbar con glassmorphism (`backdrop-blur-md`)

## 🚀 Deploy
Desplegado en Vercel con dominio propio `onzi.dev`.
